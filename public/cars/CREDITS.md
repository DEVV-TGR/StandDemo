# Créditos das fotografias

As fotografias das viaturas são provenientes dos anúncios públicos do stand
**Imperio Auto Concept** no StandVirtual
(https://imperioautoconcept.standvirtual.com/inventory), pertencentes ao stand.
Utilizadas neste projeto de demonstração para representar o inventário real do cliente.
